## Design Context
### Users
A personal Mac utility for everyday local file conversion, available during Finder drags.
### Brand Personality
Quiet, precise, tactile. Fast and elegant, as requested by the user.
### Aesthetic Direction
Refined native light/dark utility. A compact floating basket and a spacious conversion workbench. Muted jade accent, Avenir Next headings paired with Helvetica Neue body. Reference: howtoconvert.co for functionality, not branding.
### Design Principles
- Appear at the moment of need.
- Keep files local and preserve originals.
- Reveal only relevant conversion options.
- Show real engine capabilities and actionable failures.
- Respect keyboard navigation and reduced motion.

### Updated preference
User explicitly rejects native form controls. Use actual shadcn React components in a bundled offline WKWebView workbench, with the native shell retained for system drag detection and local execution.
