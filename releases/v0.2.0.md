# Dropform 0.2.0 — standalone engines

**Apple Silicon, macOS 27 or later.** This build targets the engine versions packaged on the release machine; older macOS versions are not supported by this binary.

Download the DMG, open it, drag Dropform into Applications, and launch it. No Homebrew, Python, LibreOffice or other engine installation is required. A ZIP is also available.

Includes FFmpeg, ImageMagick, Ghostscript, Pandoc, Python and LibreOffice, plus their local libraries, codecs and support resources. All conversions run locally. Engine source archives and build recipes are provided separately for developers; you do not need those to install the app.

Open at login is on by default and can be changed in Settings. Existing limitations still apply: PDF-to-document export extracts text rather than reconstructing the layout, and OCR and some specialist conversions are not yet implemented.

This is an early release, ad-hoc signed and **not Apple-notarized**. macOS may block its first launch. Bundling the engines does not resolve Apple signing/notarization.

SHA-256 checksums accompany the downloads. Third-party notices are retained inside the application under `Contents/Resources/Engines`, with source information in `LICENSES/Bundled-engines.md`.
