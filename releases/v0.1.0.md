# Dropform 0.1.0

First downloadable personal-use release for **Apple Silicon Macs (M1 or later), macOS 13+**. Intel Macs are not supported by this download.

## Install

1. Download `Dropform-0.1.0-macOS-arm64.dmg`.
2. Open the disk image and drag **Dropform** into **Applications**.
3. Launch Dropform from Applications.

A ZIP download is also available: unzip it and move Dropform.app to Applications.

This build is ad-hoc signed, **not Developer ID signed or Apple-notarized**. macOS may block its first launch; it does not provide the frictionless installation of a notarized release.

## Conversion engines

The app includes its interface and native PDF tools. Full conversion and compression support requires separate local engines. If you already use Homebrew:

```sh
brew install ffmpeg imagemagick ghostscript pandoc
brew install --cask libreoffice
```

Some document routes also require Python 3. Engine binaries are not included in this download. Available formats depend on installed engines and their codecs.

## Included

- Menu-bar app with a file drop basket
- Conversion and compression with searchable output formats
- Per-file quality, live size previews for small files, and an eye button to inspect output
- Local PDF tools, batch conversion and original-file preservation
- Settings with Open at login enabled by default
- Offline interface, Plus Jakarta Sans, and light/dark appearance

## Status and limitations

Early release, not a claim of production readiness or every possible conversion pair. PDF-to-Word exports selectable text, not the original page layout. OCR, archive extraction and some specialist routes are not implemented. Automatic basket appearance during a real Finder drag remains to be manually verified. See the repository README and COVERAGE.md for details.

SHA-256 checksums are provided in `SHA256SUMS.txt`.
